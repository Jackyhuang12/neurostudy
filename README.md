# 神经外科学习网 · NeuroSurg Learning Hub

面向医学生、规培医师、住院医师的系统学习平台：
- 一图看懂大脑（可交互脑区—功能—症状地图）
- 脑影像学入门（CT / MRI / MRA / CTA / DSA、MRI 六大序列、七步读片法）
- 病种知识库（8 大类 44 病种）
- 解剖图谱（12 张手绘 SVG）
- 手术方式（7 大类 27 术式）
- 视频资源导航（5 大类 31 入口）
- 学习路径（6 步渐进）

内容仅供医学学习交流，不构成诊疗建议。

## 本地预览

项目为纯静态站点，可直接打开 `index.html`，或使用任意静态文件服务器预览。
